# Python-beginner-basics-practice-

## Overview

This repository contains a **beginner-friendly Python practice file** demonstrating fundamental Python concepts. It is designed for anyone learning Python and includes examples with **strings, variables, lists, loops, conditionals, tuples, dictionaries, arithmetic operations**, and more.

This project reflects the learning journey of a beginner Python developer and is suitable for practice, study, or portfolio purposes.

---

## Features

The Python file covers:

- **String Manipulation**: upper, lower, title, strip, concatenation  
- **Variables and Constants**: numbers, multiple assignments  
- **Arithmetic Operations**: addition, multiplication, division  
- **Lists**: creation, indexing, slicing, adding/removing items, sorting  
- **Loops**: `for` loops with ranges and lists  
- **Conditional Statements**: `if`, `else`, logical operators (`and`, `or`)  
- **Tuples**: immutable lists  
- **Dictionaries**: creating, modifying, and accessing key-value pairs  
- **List Comprehensions**: quick generation of sequences like squares and cubes  
- **Printing and Formatting**: escape characters, f-strings
